# Android 界面与交互设计

Android 是独立发布门禁；编译、Web 检查和图稿检查不能代替设备行为验证。应用保留 Compose 导航、列表、输入和 Material 3 品牌，正文采用与 Web 共享的离线渲染模块。

## 页面结构

手机一级入口为对话、会话、任务、更多；600dp 起使用 Rail，840dp 起允许会话列表与正文双栏。更多包含调度、资源、记忆、质量、设置，管理员另含渠道工作台。二级页面隐藏一级导航并显示返回。聊天由聊天根节点消费键盘 Insets；二级表单由 Shell 消费，避免输入框和底部内容进入键盘或手势区。

正文 16sp/24sp，标准边距 16dp，间距以 8/12/16dp 为主，触控目标至少 48dp。支持系统 200% 字号，文字不可被固定高度裁切；浅深主题均使用语义颜色。顶栏、头像和状态不能挤占阅读区域。

设置行在字号达到1.5倍或可用宽度小于300dp时采用纵向布局：标题、说明和操作各自占用整行，不让尾部操作挤压文字。断点使用扣除横向安全区后的内容宽度，不能直接拿设备配置宽度推断双栏。
质量与资源页使用选中标签表达当前内容，不再重复显示同名大标题；菜单入口允许文字换行，避免系统大字号截断操作名称。
Run链路弹窗按已加载父子关系缩进，最多四层以保留阅读宽度；未加载祖先不推测层级。Trace ID可选择复制，复制操作反馈真实结果，缺失耗时显示未提供。
关闭或切换Run取消旧分页读取；重新打开同一个Run也不接收上次查看的迟到回执。

## 操作归属

|区域|常显|更多或按需|
|---|---|---|
|聊天顶栏|标题、唯一模型入口、更多|重命名、删除、压缩、快捷命令|
|输入|附件、正文、Plan/Agent、发送或停止|已选附件的移除|
|助手回复|复制、更多|审查、改进；执行详情按需展开|
|用户消息|复制、更多|编辑、重试|
|队列|内容、位置、更多|编辑、置顶、上移、下移、取消|
|连接与同步|一条状态摘要|异常时重连；详情解释具体原因|
|设置|账号执行策略、外观、Profile、应用、账号|会话配置独立归当前会话|

菜单最多一层；不能仅靠长按发现功能。删除无效按钮和重复表单，保留必要上下文入口。默认免审批时无空审批区；关闭开关后有真实审批再显示。纯许可类确认由服务端策略控制，业务澄清仍由用户回答。

普通环境账户仅提供“切换账号”，清除本机凭据、缓存与所有会话草稿；有未发送正文、附件或未确认发送时先确认，继续编辑不清理数据。测试环境另提供“退出账号及测试网关”，同时清除网关认证。两者均不停止后台渠道。诊断耗时只在显示层保留一位小数，缺失值继续显示“未提供”。

## 正文合同

共享 marked + DOMPurify + KaTeX，资源随包发布，不从 CDN 加载。支持标题、强调、引用、嵌套列表、链接、图片、表格、代码与行内/块级公式。正文不能执行注入脚本，凭据不进入 WebView。链接与附件交宿主，宽内容仅块内横滚，代码提供复制。错误公式保留可读原文。流式未闭合语法在终态完整校准。

WebView 仅服务可见内容，离开组合即销毁，当前不保留空闲实例。共享渲染器缓存最多32份正文、合计524288个UTF-16字符；公式缓存最多64项、每项最多8192字符。Android 按4ms窗口合并流式更新，低于50ms合并预算；终态立即提交。临时增量只更新 UI，持久事件更新游标，禁止每个 token 拉取快照或写磁盘。进入后台和终态提交缓存。

## 状态与体验

快捷命令目录在构建时直接打包协议包的 commands.json，提供中文名称、说明、权限和搜索；选择条目填入命令框，点击执行才提交。保留参数命令输入，Core 只执行其支持的命令映射。关闭弹窗不取消已发送写入，账号切换仍隔离回执。
未提交的命令修改在关闭时确认；搜索条件本身不算业务草稿。

发送回执前冻结该次草稿，失败保留正文和附件；超时先核对记录，不自动重发。明确区分排队、准备、执行、校验、生成、停止中、失败及离线；准备、执行和校验阶段均保留停止入口，状态采用v16 Run状态。历史阅读不抢滚动，接近末尾才跟随；“最新消息”只在偏离末尾时出现。草稿原子存储；新建、切换、返回、旋转及后台恢复不丢未提交正文。首次进入会话定位末尾，当前会话内上翻阅读保持跟随状态。

登录、会话、任务、调度、资源、记忆、质量、设置和渠道页面采用一致加载、空态、错误和反馈；没有数据不能呈现成功状态。设置保存以服务端回执为准，离线禁止修改账号策略。

注册发行的令牌只有复制成功或勾选“我已手动保存令牌”后才能继续进入；发行新令牌时重置确认状态，剪贴板失败保留可选文本并显示错误。质量诊断提供最近24小时、7天、30天，刷新以单个结束时刻计算明确区间，显示报告实际起止时间。

知识文件上传和知识源登记共同归账号ViewModel任务所有；页面离开只取消等待，不在两个步骤中间取消业务操作。切换账号取消旧任务，并校验每次写入回执所属账号；失败显示明确错误，结果未知时不自动重试。
资源目录与技能安装表单打开后停用重复入口，取消走未保存确认；提交期间锁定字段。创建成功回执先关闭并清空表单，再刷新列表，刷新失败不恢复可重复提交的表单。

会话标题与身份、任务、调度、资源目录/技能路径、Profile 表单注册未保存状态；会话设置逐字段保存服务端基线，恢复或远端变更只更新未修改字段；一级导航、二级返回与系统返回（包括平板双栏首页）先检查修改，默认焦点为“继续编辑”，确认放弃只清理对应表单。调度和资源表单取消使用同一确认。重命名、消息编辑、队列编辑取消时只确认当前弹窗的修改，只有写入回执成功才自动关闭；Profile刷新保护未保存内容，旋转恢复后的自动读取保留已恢复的脏草稿，保存直接采用写回执；下载完成由系统短提示反馈，不保留无人读取的JSON结果状态。管理写请求归账号 ViewModel 所有，页面返回只停止等待，不取消已经发起的写入；失败进入全局错误区，重入页面重新读取服务端状态，账号切换会取消旧任务。所有表单、模态编辑与账号切换组合仍须按发布验收中的缺口逐项核验。

WebView 的高度回执只在 Compose 测量阶段读取，不使整段正文重新组合与转义；主题与脚本参数按正文和主题变化缓存。网络连接、超时与 TLS 失败显示可操作中文。渠道未配置时显示管理员配置说明与重试，不展示可用扫码或自动回复的假状态。详情只翻译协议状态和布尔值，用户记忆正文原样显示。

头像在会话加载后使用后台线程采样解码，最大边长512像素，当前会话所有消息共享同一Bitmap，不在每条消息重组时解码原图，也不长期保留压缩字节。上传和恢复默认头像立即更新当前显示；头像图像回执核对账号、会话与附件ID，避免过期读取覆盖新头像。附件预览在后台采样解码，加载中、格式不支持和成功分别显示；切换附件取消旧解码并重置状态。远程预览复用OkHttp/Okio，按20MiB上限有界读取，未知长度也检查实际数据量，支持项目最低API26。
会话快照的身份字段同步到列表与设置，包含其他设备修改的标题、模型和头像；非当前会话仅更新身份，不拉取或解析历史正文。头像读取只在附件ID改变或显式重新进入时触发。

队列读取、排序、置顶、取消和编辑的回执核对发起账号与会话；切换后旧回执不覆盖当前队列、加载状态或弹窗。计划确认、消息编辑/重试/审查/改进、审批、压缩和取消也不抢回旧会话。名称、模型、队列模式及头像回执更新发起会话列表，不清理当前会话加载状态；写操作在启动协程前锁定提交入口。删除当前会话清除发送、取消、附件和未确认发送状态，并清除对应草稿、缓存与投影，保留已切换到的新会话。身份缓存先在主线程取得一致的会话和游标，再交给存储线程；存储失败进入错误状态，不让异常结束应用。

## 设备验收

应用状态由AndroidX生命周期感知组件收集，页面退到后台停止重组，账号ViewModel继续接收、投影和保存Run结果，前台恢复后读取最新状态。正文比较保留上次渲染结构，图片失败状态与复制反馈不会导致未变块重复替换。

窄屏、平板、横屏 × 深浅色 × 100%/200% 字号；覆盖真实键盘、系统返回、草稿、长历史、流式表格/公式、图片、失败重试、换账号、后台恢复和离线。核心页面保留前后截图、测试记录和产物校验值。

统计应用及 WebView 进程内存、CPU和帧耗时；本地受控增量到显示 p95≤100ms，正常交互无超过700ms冻结帧。截图检查文字裁切、按钮触控、正文宽度、读屏名称与对比度；模拟器结果与真机结果分开记录。
