UmaAgent 前端设计实施规格

通用Agent对话、执行计划、后台任务和管理员渠道工作台的独立前端实施合同。

文档修订日期：2026-09-17。本文是目标设计合同，不代表当前代码已实现全部目标行为。设计图为可编辑 SVG 结构稿，不是产品运行截图，也不是 ImageGen 输出。

1. 权威顺序与实施范围

电脑端为Windows浏览器/Web/PWA，当前没有Electron或原生Windows客户端，禁止凭空增加托盘进程。Android为Compose，手机/平板同一业务合同。普通用户与管理员入口按服务端角色决定；管理员可在同一身份下进入普通Agent工作台，切换普通账号是另一项操作。CLI不作为图形前端。

同一交付中：交互表和字段规则 > 几何规范 > SVG 示例值。示例值是合成测试数据，不是默认业务数据。业务状态只取服务端或本地桥接回执；画面不允许推断业务成功。若未来协议改变，必须升级本文件与 spec.json；不得让开发者自行猜测一个静默替代行为。

统一交互规则（适用于下文每个界面和动作）

G01：进入页面先读缓存（若存在且属于当前账号），标记“上次同步”；同时发起只读刷新。首次无缓存显示骨架；成功空数组才显示“暂无…”。失败不删除已有数据。未知数值显示“未提供”，绝不能显示0冒充测量值。

G02：点击任一写操作立即禁用该动作和冲突操作，按钮文字“处理中…”，输入保持；远端业务写入只在服务端明确成功后显示成功并清空对应草稿；纯本地动作与系统桥接按G13的本地完成条件判断。失去连接或超时显示“结果尚未确认”，先查询资源状态再允许重发；非幂等操作不得静默自动重试。只读请求可手动重试。

G03：关闭表单/切换账户前如有未保存修改，弹“放弃未保存内容？”；默认焦点“继续编辑”，另有“放弃并离开”。普通页返回不弹确认。关闭模态层先返回其父层，焦点恢复到触发控件；正在提交时可离开但不假称操作被取消，后台结果按资源ID归并。跨账号迟到响应一律丢弃。

G04：表单字段规范是UI约束，不能放宽协议上限。字符串按Unicode字符校验；仅在提交时去除首尾空白，正文保留换行与内部空白。字段失焦校验；提交先定位第一处错误；服务端422/400映射到字段，未能映射的显示表单顶部。未在字段表中列出的字段不允许由设计实现者自行新增。

G05：Web/Windows Enter发送、Shift+Enter换行，输入法正在组合（isComposing）时Enter只确认候选；Android多行IME默认换行，使用显式发送按钮。正文与附件均为空时禁发；仅附件发送使用默认提示词。离线保留草稿但禁发；恢复连接后不自动发送。消息发送与文件上传分开反馈。

G06：用户距底部≤80px时新增消息跟随；向上滚动超过80px暂停跟随，显示“查看新消息”；加载历史保留首个可见消息ID与偏移。打开/关闭检查器不重置会话。草稿按账号和会话隔离。Android 原子保存草稿及未确认发送ID，支持进程恢复；退出账号清除本机草稿。Web 草稿仅当前页面生命周期。重命名/主题/导航展开状态允许本机偏好保存，不保存Token或正文到普通偏好存储。

G07：401先结束当前订阅，显示重新登录；403解释权限不足且不可通过按钮重试升级权限；404显示资源已不存在并返回列表；409重新获取最新状态并展示差异；429依据Retry-After倒计时；5xx允许手动重试读取。错误Toast不替代持久错误区。认证失败不循环重连。UI 15秒未确认提示“仍在等待”；60秒转“结果尚未确认”并允许查询，不能当作服务端已失败。

G08：时间以协议值存储（ISO UTC或epoch毫秒依本项目），显示到本地时区；列表用相对时间，详情显示YYYY-MM-DD HH:mm:ss UTC±hh:mm。日期边界采用用户选择时区，不固定+8。所有示例名/时间/文件为合成数据。

G09：所有控件用原生按钮/输入语义；Tab按视觉顺序、Esc关闭最上层弹窗；焦点圈全程可见；读屏按标题、状态、正文、操作顺序；错误用role=alert，流式按段以polite播报。触控最小48dp，不依赖hover/滑动唯一操作。字体200%时允许重排，禁止裁掉按钮文字。

G10：手机IME与系统底栏不叠加：内容底部留白=max(IME.bottom,systemBars.bottom)，只有最外层消费系统Inset；键盘打开隐藏底部导航，输入框外底边距键盘顶部8dp，容差±2dp。Web嵌入容器使用可用动态视口高度，父壳与子页面不得同时增加bottom padding。系统返回优先收键盘、再收Sheet、再退页面。

G11：界面图绑定的事件ID是验收ID。每条动作至少执行正常完成、不可执行/失败、双击和返回四类测试；local/system使用本地或系统完成条件，read/write使用远端回执；图片里的成功/失败是从处理中分支，绝不能按图横向顺序理解为成功后自动失败。任何与UI无关的trace/requestId只在“诊断详情”折叠区提供，不挤占普通工作流。

返回/取消 返回触发页面，恢复原焦点/滚动；未保存输入按G03确认；在途操作不被伪装取消。
验收 Given 操作前示例数据；When 触发“拒绝提案”；Then 只有真实回执后呈现上述结果。另模拟失败、双击、离开页面，核对G02/G03。

页面验收

本页每个字段、每个动作和全部失败分支都有对应UI；320宽和200%字号可滚动到所有控件。不得用空值模拟成功。绑定见本页来源文件；实现检查本页所有事件ID。

6. 平台与系统级行为

Windows Web/PWA：浏览器/系统窗口控件位于右侧；支持Ctrl+K命令、Ctrl+F浏览器查找（不抢占），不使用macOS Command键提示；PWA安装入口只在浏览器提供安装事件时显示。

Android：底部固定对话/会话/任务/更多；更多包含调度、资源、记忆、质量、设置，管理员额外咸鱼入口；≥600Rail、≥840会话列表+正文双栏。系统文件选择器取得URI后上传，不承诺进程被杀后上传继续；返回前台重新检查附件状态，失败项保留手动重试。

消息通知只显示已授权内容摘要；无当前系统通知实现的能力不得显示已通知。本机外观支持跟随系统、浅色和深色，采用品牌绿。所有角色切换使用独立标题，普通工作台入口与“切换普通账号”明确分开。

7. 发布验收门槛

  1. 页面注册表全部可通过规定入口到达，返回后定位不丢失；没有孤立按钮、无意义“继续”按钮、正文写JSON或未说明的占位框。
  2. 每个事件ID核对前置/处理中/成功/失败/返回，写请求双击只产生一次有效动作。断网/超时不能显示成功或重放未知写请求。
  3. 像素验收以SVG中的结构和几何表为基准：布局尺寸偏差≤2px/dp，字体使用指定系统栈；系统标题栏、字体栅格化、平台文件选择器由OS决定，不要求跨OS像素一致。
  4. 覆盖Web 1440×900/1024×768/390×844/320×640；Android 390×844、600×960、840×900、1024×768，字体100%/200%，深浅色、键盘打开、长文本；Windows Web/PWA另测125%/150%浏览器缩放；当前无原生桌面客户端，不设置托盘验收项。
  5. 对比度：普通文字≥4.5:1，大标题和控件边界≥3:1；Tab/读屏/减少动态效果通过；账号隔离、403深链、离线只读、换账号迟到写入逐条验证。
  6. 设计校验仅证明设计资料、源码绑定与静态图稿自洽。设备、网络、性能及真实模型以 docs/release-acceptance.md 的独立实测结果为准；全局 G03/G14 的所有表单丢弃确认尚未完成逐项验证，不得标为已实现或已验收。
