# UmaAgent Android 1.4.7（21）

## 当前工作区体验

- 咸鱼总控提供“切换普通账号”，只清理本机管理员会话，不停止后台 Adapter 或删除咸鱼 Cookie。
- Material 3 App Shell 使用系统 Insets，顶部内容不会遮挡通知栏，窄屏使用底部导航，宽屏使用 Navigation Rail。
- 会话页压缩窄屏底部导航和消息输入区的固定高度，保留至少 48dp 触控目标；正文、标题、输入、状态和导航标签使用分层字号。

## 本轮候选版本

- 1.4.7（versionCode 21）：管理页面回执统一在主线程提交，避免数据更新后加载状态不结束；优化共享正文增量渲染并完善链路诊断，保留历史凭据、离线缓存与草稿。正式签名、覆盖升级及发布状态以发布验收文档为准。

## 上一正式版本

- 1.4.6：修复会话卡片遮挡/闪动和历史阅读时自动跳尾；异步 WebView 高度回执不会覆盖新正文。冷启动缓存、凭据和快照解析移出主线程，WebSocket 认证读取也不再阻塞主线程；WebView 渲染进程意外退出时切换为纯文本正文，保持会话可读。
- 1.4.6（versionCode 20）正式发布，release `20-99a0b09`；APK SHA-256 `cc339eb6dffdcaaa36db30a517ad1ec1bddc7fce98121ab4fbf1c1549d8faf15`。WebView renderer 异常退出专项已在 API 36 模拟器通过；真机长期闪退情况仍待真实设备日志观察。

## 更早版本

- 1.4.5：修复长会话问题与回复正文显示，并避免 Android 历史浏览时列表自动跳回底部；正式 release `19-086cc28`，APK SHA-256 `ae3e8e3246dcecba14f928fafda0585e181f430d02c0752a429000186eedd182`，签名证书与前版一致。


- 1.4.3：统一当前 Core/Protocol/schema 契约，完善队列版本回执、Trace 树展示和跨账号回执隔离。

- 与 Core `1.3.0` / Protocol `16`、业务 schema `27` 同步；旧接口与旧本机缓存不再兼容。
- 手机采用对话、会话、任务、更多四个入口；600dp 起使用侧栏，840dp 起提供会话双栏。
- 聊天正文共享离线 Markdown、KaTeX 公式和清洗模块；代码、表格块内横滚，支持代码复制、图片预览与保存。
- 账号级免审批默认开启，设置保存以服务端回执为准；普通工具、命令、计划及调度统一生效。
- 支持临时流式增量、断线游标补拉、冷启动离线阅读、草稿与未确认消息 ID 恢复；失败保留输入，重试先核对服务端记录。
- 准备、执行和校验阶段保留停止入口，状态文案采用当前Run状态。
- 消息与队列操作整理为一层菜单，任务可展开全文；Run 链路诊断可查看阶段、错误并重试读取。
- 设置在大字号和窄栏下采用纵向操作布局；诊断提供24小时、7天、30天时间窗和直接可读摘要。
- 快捷命令与Web共用协议目录，支持中文搜索、名称、说明和权限提示；关闭弹窗后已提交的命令继续完成。
- 普通设置合并重复退出入口，切换账号前确认所有会话未发送草稿；未提交的快捷命令修改在关闭时确认。
- 质量与资源多标签页去除重复大标题，耗时显示一位小数，菜单入口支持大字号换行。
- 会话头像后台采样并共享解码结果，上传及恢复默认后立即刷新；附件预览后台解码并显示加载状态，损坏图片切换后清除旧状态；远程图片使用Okio有界读取，保留API26支持。
- 页面进入后台停止重组，运行继续接收并保存；返回前台读取最新结果，强杀后可离线读取已保存正文与草稿。
- 会话快照同步其他设备修改的名称、模型和头像；非当前会话更新列表，过期头像读取不会覆盖新会话。
- 队列及会话写入回执绑定发起会话，切换后不跳回旧会话、不覆盖当前操作状态；模型切换成功或失败的迟到回执均隔离；删除同步清理对应草稿、附件与发送状态。
- 注册令牌需复制成功或确认手动保存后继续；会话与Profile恢复保留未提交字段，知识上传离页后完成登记。

- 管理员 PAT 登录后自动进入咸鱼工作台，普通账号继续进入 UmaAgent。
- 咸鱼总控和买家会话随服务端同步，支持扫码登录、自动回复开关和草稿发送。
- 自动回复关闭时回复只保存为草稿，管理员确认后才会发送给买家。
- Android 13+ 在管理员进入咸鱼工作台后请求新消息通知权限。
- 管理员使用 Core PAT，普通用户使用独立 PAT，客户端只保存当前令牌。

该版本必须使用现有生产签名 keystore 构建。Debug APK 仅用于本地验证，不能放入生产下载清单。
